# 铃铛的车库 🔔

我的汽车收藏展示网站 —— 不罗列所有车型，只陈列让我心动的那几台。

## 技术栈

- 纯静态网站：HTML + CSS + JavaScript（零依赖，零框架）
- 数据驱动：车型数据存放在 `data/cars.js`，展示清单存放在 `js/favorites.js`
- 滚动大片式动画：每台车一整屏，驶入 + 扫光 + 参数逐条弹出
- 深色影院风主题，每台车有专属主题色

## 页面结构

| 页面 | 说明 |
|------|------|
| `index.html` | 我的车库（开场 + 全屏滚动展示收藏） |
| `car.html` | 车型详情页（参数、配置、价格） |
| `brand.html` | 品牌页（该品牌全部车型） |
| `search.html` | 全站搜索 |

## 如何修改收藏

编辑 `js/favorites.js`，每台车一行：

```js
{ id: 'byd-u8', tagline: '原地掉头，还能应急浮水', color: '#d4a017' },
```

`id` 可从 `data/cars.js` 中的 62 款车型里任选。
